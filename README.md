# Advanced Geovisualisation

This is the webpage of the module *Advanced Geovisualisation (ENVS456)* offered in the [MSc in Geographic Data Science](https://www.liverpool.ac.uk/courses/geographic-data-science-msc) at the University of Liverpool, Department of Geography and Planning.

The module is designed and taught by [Gabriele Filomena](https://www.liverpool.ac.uk/people/gabriele-filomena) and [Elisabetta Pietrostefani](https://www.liverpool.ac.uk/people/elisabetta-pietrostefani), from the Geographic Data Science Lab.
